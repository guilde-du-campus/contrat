1. Cycle de vie d'une quête (états-transitions)

Le schéma pivot des deux modules : il dicte les actions que l'API accepte et les boutons que le front affiche.

stateDiagram-v2
    direction LR

    [*] --> OPEN : createQuest
(récompense sous séquestre)

    OPEN --> IN_PROGRESS : take
(prise par un aventurier)
    OPEN --> CANCELLED : cancel par l'auteur
(séquestre remboursé)

    IN_PROGRESS --> OPEN : abandon du preneur
(retour au tableau)
    IN_PROGRESS --> COMPLETED : complete
(fin déclarée par le preneur)

    COMPLETED --> VALIDATED : validate par l'auteur
(récompense créditée, XP, badges)

    VALIDATED --> [*]
    CANCELLED --> [*]

    note right of OPEN
        Modifiable par l'auteur
        uniquement dans cet état
    end note

    note right of VALIDATED
        LA transaction du domaine :
        transfert des points,
        attribution d'XP aux deux,
        évaluation des badges
    end note

2. Le domaine (diagramme de classes)

Les entités, leurs relations et les opérations du domaine. Le niveau et le titre honorifique sont calculés, jamais stockés.

classDiagram
    direction LR

    class Adventurer {
        +UUID id
        +String username
        +String email
        -String passwordHash
        +String avatarUrl
        +Int xp
        +Int helpPoints
        +Role role
        +DateTime memberSince
        +level() Int
        +honoraryTitle() String
        +canAfford(reward) Boolean
    }

    class Quest {
        +UUID id
        +String title
        +String description
        +QuestType type
        +QuestCategory category
        +QuestStatus status
        +Int reward
        +String photoUrl
        +DateTime createdAt
        +DateTime takenAt
        +DateTime completedAt
        +DateTime validatedAt
        +take(taker)
        +abandon()
        +complete()
        +validate()
        +cancel()
    }

    class Badge {
        +String code
        +String name
        +String description
        +String icon
        +Boolean automatic
    }

    class BadgeAward {
        +DateTime awardedAt
    }

    class Role {
        <>
        MEMBER
        GUILD_MASTER
    }

    class QuestStatus {
        <>
        OPEN
        IN_PROGRESS
        COMPLETED
        VALIDATED
        CANCELLED
    }

    class QuestType {
        <>
        HELP
        BARTER
    }

    Adventurer "1" --> "0..*" Quest : poste (author) >
    Adventurer "0..1" --> "0..*" Quest : prend (taker) >

    BadgeAward "0..*" --> "1" Badge : référence >
    Quest --> QuestStatus
