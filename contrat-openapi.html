API de la Guilde, la plateforme d'entraide et de troc du campus.

Le principe

Un aventurier poste une quête (une demande de coup de main ou un troc). Un autre la prend, la réalise, puis l'auteur la valide. La validation transfère la récompense en points d'entraide (helpPoints) et fait gagner de l'expérience (xp), parfois un badge.

Authentification

Toutes les routes (sauf l'inscription, la connexion et la consultation publique du tableau des quêtes) exigent un jeton JWT transmis dans l'en-tête Authorization: Bearer <jeton>. Le jeton d'accès expire au bout de 15 minutes, le jeton de rafraîchissement au bout de 7 jours.

Erreurs

Toutes les erreurs suivent la RFC 7807 (application/problem+json) : un type, un title, un status, un detail lisible par un humain. Les textes destinés aux utilisateurs sont en français.

Temps réel

Les notifications passent par WebSocket sur /v1/realtime (voir la section « x-realtime » en bas de ce fichier).

Codex GraphQL

La consultation (lecture seule) est aussi exposée en GraphQL sur /v1/codex. Le schéma vit dans le fichier codex.graphql.

Quests

Le tableau des quêtes et leur cycle de vie

Le tableau des quêtes

Route publique : le tableau se consulte sans compte, c'est la vitrine de la Guilde. Filtres cumulables, pagination par page.

query Parameters
page
integer >= 1
Default: 1

Numéro de page, à partir de 1

limit
integer [ 1 .. 50 ]
Default: 20

Nombre d'éléments par page

status
string (QuestStatus)
Enum: "OPEN" "IN_PROGRESS" "COMPLETED" "VALIDATED" "CANCELLED"

Le cycle de vie complet est décrit par le diagramme d'états-transitions (diagrammes/cycle-vie-quete.mmd). En résumé : OPEN -> IN_PROGRESS (take) -> COMPLETED (complete) -> VALIDATED (validate), avec les chemins IN_PROGRESS -> OPEN (abandon) et OPEN -> CANCELLED (cancel).

type
string (QuestType)
Enum: "HELP" "BARTER"

HELP = un coup de main, BARTER = un troc (objet ou service)

category
string (QuestCategory)
Enum: "DEV" "DESIGN" "COURSES" "MATERIAL" "STUDENT_LIFE" "OTHER"
authorId
string <uuid>

Les quêtes postées par cet aventurier

takerId
string <uuid>

Les quêtes prises par cet aventurier

q
string <= 100 characters

Recherche plein texte sur le titre et la description

sort
string
Default: "-createdAt"
Enum: "createdAt" "-createdAt" "reward" "-reward"
